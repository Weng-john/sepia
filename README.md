# sepia-dist

Ready-to-install build of the customized sepia skill: upstream [Nanako0129/sepia](https://github.com/Nanako0129/sepia) (MIT) plus the overlay on the `sepia-tw` branch.

- `sepia/` — the skill folder; copy it to `~/.claude/skills/sepia`
- `VERSION` — the build in this branch

This branch is regenerated by the weekly build. Do not edit it by hand; change `sepia-tw` instead.
